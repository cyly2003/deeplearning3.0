# v1.0.0 重构后初始对比报告

## 运行目的

本报告记录 v1.0.0 重构后的 smoke 和两个指定历史任务对照，目标是确认新架构能够稳定跑通，并为后续正式长训练提供可比路径。

注意：本次新版对照只跑 1 个预训练 epoch，迁移任务额外跑 1 个土壤微调 epoch；旧版结果多为 30 epoch。因此本报告不能直接作为最终性能优劣结论，只用于确认重构后的数据流、任务流和输出结构。

## 本次重构重点

| 模块 | 调整 |
| --- | --- |
| 任务分配 | EC/LC、NOEC、LOEC 为主任务；IC/AC/ED/LD/MATC/BMD/BMC 等为辅助毒性任务 |
| 样本保留 | 放宽终点和效应家族映射，QC 后聚合样本从较窄毒性集合扩展到 326,612 条 |
| 目标尺度 | 使用 target_name、medium_domain、adapter_name 和 target_scale_key 区分水相 pTox、土壤 pTox、土壤 mg/kg 等目标 |
| 训练稳定性 | 增加 per_task_target 标准化、AdamW、weight decay、梯度裁剪、任务权重平衡 |
| AD 评估 | Williams leverage、指纹 PCA 等只用训练集拟合，避免测试集信息泄漏 |
| 输出命名 | 新实验目录使用 `v1.0.0_中文一句话名称` 格式 |

## 解读

1. 新版不是简单在旧数据上多训练一次，而是扩大了任务范围和样本范围。新版水相 B split 的 test 样本从 1,799 扩大到 31,011，任务头从 4 个扩大到 107 个，因此 1 epoch 指标低于旧版 30 epoch 不代表“重构负优化”。
2. 新版迁移 f20 的 test 样本从旧版近似对照的 286 扩大到 2,163，任务头从 7 个扩大到 44 个，并且只微调 1 epoch，因此当前负 R2 主要说明模型尚未充分收敛。
3. 新版输出中已经保留 task_group、target_name、medium_domain、adapter_name、target_scale_key 等字段，后续可以直接按主任务、辅助任务、水相、土壤、终点家族分层诊断。
4. `"nan"` SMILES 被当作真实 SMILES 的问题已经修复；当前仍出现的 RDKit warning 主要来自真实的氢原子 SMILES，不再是缺失值污染。

## 下一步正式对比建议

| 目的 | 建议 |
| --- | --- |
| 判断是否真正优化 | 在新版上跑与旧版相同训练预算的 30 epoch，并至少保留 B split 与 f20 迁移两条线 |
| 判断放宽聚合是否有效 | 同时报告主任务指标和辅助任务指标，不用辅助任务指标替代主任务指标 |
| 判断土壤小样本贡献 | 增加 soil-only f20 基线，与 aquatic-pretrain + soil-finetune 成对比较 |
| 判断应用域增强 | 在 AD 内外分别报告误差，并给出不确定度或 AD 标记 |
| 判断 BAF/BCF 解释价值 | 单独构建富集因子辅助目标后，再看其对毒性主任务和 SHAP 解释的贡献 |
