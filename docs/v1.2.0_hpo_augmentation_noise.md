# v1.2.0 自动调参、训练增强与测试扰动说明

## 核心口径

- `metrics.csv` 仍然只记录干净样本预测结果，不混入测试扰动样本。
- `finetune_validation` 是从原 `finetune` 内部切出的微调验证集；它不参与微调训练、目标标准化、类别映射或数值标准化拟合。
- HPO 默认只优化 `finetune_validation`/`validation` 上 ECx、NOEC、LOEC 主任务的加权 MAE，不使用最终 `test` 调参。
- `aquatic`/`soil` 来自预测表的 `medium_domain`，应结合 `split_part` 解释；`train + aquatic` 通常表示水相预训练样本在最终模型上的 in-sample 预测，不等同于独立水相测试。

## 推荐远端 HPO 入口

在远端项目目录执行：

```bash
python scripts/run_transfer_hpo.py \
  --config configs/experiment.remote.easyai.yaml \
  --db outputs/derived/modeling_dataset_v2_0_0_rebuild.sqlite \
  --split-name M_qc_aquatic_to_soil_ptox_adapt_C_f20 \
  --out-root outputs/experiments/v1_2_0_自动超参数优化_迁移验证 \
  --trials 12 \
  --epochs 30 \
  --device cuda:0
```

输出：

- `hpo_trials.csv`：每个 trial 的参数、状态、目标值和 metrics 路径。
- `best_trial.json`：验证集目标最优的 trial。
- 每个 `trial_*/train.log`：单次训练日志。

## 单次训练增强与扰动

示例：

```bash
python -m qsar_tl.training.train \
  --config configs/experiment.remote.easyai.yaml \
  --db outputs/derived/modeling_dataset_v2_0_0_rebuild.sqlite \
  --split-name M_qc_aquatic_to_soil_ptox_adapt_C_f20 \
  --run-version v1.2.0 \
  --run-name-zh 土壤迁移_增强扰动_同预算复跑 \
  --epochs 30 \
  --finetune-epochs 40 \
  --monitor-split internal_train_fraction \
  --finetune-validation-fraction 0.2 \
  --augment-finetune-replicates 2 \
  --augment-numeric-noise-std 0.03 \
  --test-noise-replicates 5 \
  --test-noise-numeric-std 0.03 \
  --device cuda:0
```

扰动输出：

- `test_noise_predictions.csv`：测试样本每次扰动的预测。
- `test_noise_summary.csv`：每个原始样本的扰动预测均值、标准差和误差。
- `test_noise_metrics.csv`：使用扰动均值计算的分组指标。

## medium 样本量审计

```bash
python scripts/audit_prediction_medium_counts.py \
  --predictions outputs/experiments/.../predictions.csv
```

输出目录默认是同一 run 下的 `medium_audit/`，包含 split、task、target、medium 与原始 `primary_medium/media_type/target_basis` 的交叉计数。
