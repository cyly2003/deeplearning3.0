# v1.2.48：结构相似度分层覆盖度分析（严格外部结构家族测试）

## 目的与结论边界

本分析用于补充“模型在不同化学空间覆盖程度下的误差表现”，而不重新训练模型。它只使用一个预先锁定、按验证集 MAE 选出的单种子模型，并对其锁定外部测试预测进行后处理。

随机 8:2 划分仅作为可行性审计：在该边界中，大多数结构相同的母体化合物同时位于模型拟合数据和测试集，因而不能据此形成化学外推（similarity-decay）曲线。正式分层因此使用 v1.2.47 的严格结构家族外部测试；其开发/测试边界仍为外层 80:20，开发集内部为 80:20，即全体 64/16/20 train/validation/test。

## 锁定模型和选择

- 运行：`v1.2.47_SF-M10_scaffold_family`
- 模型：仅水相预训练（M10）
- 报告种子：3407
- 选择规则：仅以验证集 MAE 最小为主，R2 仅作并列时的次级规则；选择过程不读取外部测试指标。

该分析不把严格结构家族测试的数值同随机 8:2 的预测分数直接作性能比较，也不用于建立 M10 对其他模型的因果优势。

## 相似度定义

对每个结构标准化后的外部测试化合物，计算 Morgan 指纹（radius=2，2048 bits）与模型拟合化合物的最大 Tanimoto 相似度：

`Smax = max[Tanimoto(test_parent, fit_parent)]`

- 主分析：测试结构与 M10 Stage 1 或 Stage 3 中所有用于拟合的结构比较（`all_model_fit`）。
- 敏感性分析：仅与 Stage 3 土壤训练结构比较（`stage3_soil_fit`）。

## 分层与统计

主性能曲线按外部测试集中**去重 canonical parent 的经验 Smax 四分位点**生成四个互斥区间；样本行在其化合物所属区间内计算指标。这样保留真实相似度分布，并避免固定阈值在严格隔离边界下产生空层。

同时逐一报告预先指定的累计阈值：`Smax < 0.80`、`< 0.65`、`< 0.40` 与 `< 0.20`，用于与既有 0.65 scaffold/similarity 叙事对应。阈值表不是互斥分层曲线。

每个互斥层报告：

- 样本行数、canonical parent 数、严格结构家族 component 数；
- R2、RMSE、MAE；
- 按任务均值中心化的 within-task R2；
- 以外部测试结构 component 为重采样单位的 5,000 次 percentile 95% bootstrap CI。

支持规则为每层至少 100 个样本行和 10 个 canonical parent。若某一层不达标，只作描述性输出；相邻固定区间的合并不使用任何模型性能值。经验四分位分层的边界完全由相似度决定，也不使用预测误差或标签。
