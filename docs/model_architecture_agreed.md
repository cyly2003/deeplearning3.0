# 已确认 QSAR 迁移学习模型架构

更新时间：2026-06-11

## 1. 总体定位

当前主模型是一个面向 ECOTOX 条件聚合样本的多任务 QSAR 迁移学习模型。模型目标是在给定化合物结构、物种信息、暴露介质、暴露路径、life stage、暴露时长和任务终点时，预测 EC/LC、NOEC、LOEC 下各效应终点的毒性目标值。

## 2. 输入模块

### 2.1 分子主信号

- RDKit 分子描述符作为主信号。
- Morgan 指纹作为结构辅助信号。
- Morgan 指纹位数固定为 512 bit。
- 分子描述符与指纹共同构成分子主分支。

### 2.2 物种与生态上下文

- 物种分类学层级 embedding：kingdom、phylum、class、order、family、genus、species。
- life stage embedding。
- 暴露介质、暴露路径、生境等实验与生态上下文变量。

### 2.3 暴露时长

暴露时长是连续变量，不只作为离散 embedding。

处理方式：

- 聚合阶段仅合并极接近暴露时长，例如 95.9 h、96 h、96.1 h。
- 聚合后保留代表性连续时长。
- 输入阶段使用连续时长及其非线性展开：
  - `duration_h` 或 `duration_bin_h`
  - `log1p(duration_h)`
  - `sqrt(duration_h)`
  - `1 / (1 + log1p(duration_h))`
  - RBF 时间基函数，中心包括 24、48、96、168、336、720 h。

该设计用于捕捉暴露-毒性关系中的非线性、平台期和近似 S 型响应。后续解释分析中，暴露时长必须单独输出 PDP 或 ALE。

## 3. 辅助任务

BAF/BCF 不作为主毒性模型的普通输入特征，而作为辅助任务标签参与多任务学习。

原因：

- 如果 BAF/BCF 来自同一数据集观测值，并作为输入用于预测毒性，容易造成信息泄漏。
- 作为辅助任务时，模型可通过共享主干学习生物富集和污染物生物有效性相关知识。
- 缺失 BAF/BCF 不插补，使用 mask loss，仅对真实有标签样本计算辅助损失。

经口暴露系统毒性同样作为辅助任务，以较低任务权重参与训练。

## 4. 主任务头

主任务只使用 EC/LC、NOEC、LOEC 下各效应终点。

- LC 归入 ECx/死亡相关任务头。
- 任务头按“endpoint family + effect family”组织。
- 低样本任务头不纳入正式训练或正式指标报告。

默认低样本阈值：

- 总样本数不少于 200。
- 训练集样本数不少于 100。
- 评估集样本数不少于 30。
- 5 折交叉验证中每折测试样本数不少于 20。

## 5. 网络结构

当前深度网络采用：

1. 分子主分支：RDKit 描述符 + 512 bit Morgan 指纹。
2. 上下文分支：物种分类学、life stage、介质、路径、时长等变量。
3. 共享主干：多任务共享 MLP。
4. 分子残差：分子主分支通过线性投影注入共享表示，保留 QSAR 主信号。
5. 多任务输出头：每个任务头独立回归输出。

## 6. 实验解释重点

- 随机划分结果只代表同分布拟合能力上限。
- 化合物严格划分用于评估新污染物外推能力。
- 5 折化合物严格不跨折用于更稳定评估结构外推。
- 介质迁移实验用于判断水相、沉积物、土壤之间的知识迁移是否有效。
- 暴露时长模块需通过消融、PDP/ALE 和残差分析判断是否捕捉平台期。
