## Strategy Priorities For Improving Model Performance

### Priority 1: lock final evaluation before adding another method family

The current fixed test set has already influenced several decisions. Before a
new large strategy matrix, create a locked final validation plan:

- A new independent split or external validation subset if available.
- A clear rule for final model selection before looking at final metrics.
- Single-model mean, 5-seed ensemble, AD strata, endpoint-family metrics, and
  risk-bin metrics reported together.

This step improves scientific credibility more than another small metric gain.

### Priority 2: add risk-aware evaluation and training

Current MAE is around one log10 unit, which is acceptable for some continuous
QSAR reporting but risky for threshold-based ecological risk classification.
The next evaluation layer should include:

- Authority-bin confusion matrix.
- Within-one-bin accuracy.
- High-risk recall.
- False downgrade rate.
- Boundary-zone metrics for samples close to risk thresholds.

After evaluation is stable, training can add:

- Threshold-near sample weighting.
- Asymmetric penalty for high-risk false downgrades.
- Regression plus ordinal/risk-bin multitask learning.

Do not replace MAE with Huber loss for interpretation. Huber loss is useful for
optimization robustness, but risk misclassification needs threshold and bin
metrics.

### Priority 3: improve species and task-family extrapolation

AD results show that species and task-family coverage are central risk layers.
Likely improvements:

- Hierarchical taxonomy features or embeddings rather than only flat species
  identifiers.
- Species/task-family-aware reweighting.
- Leave-species-group-out diagnostics.
- Prediction intervals or conformal uncertainty for species-extrapolation rows.

This is more aligned with ecotoxicology than only tuning chemical similarity.

### Priority 4: refine censored-data modeling

Censored loss improved the f100 mainline, but the current implementation is a
generic penalty. More rigorous variants to test after final evaluation is
locked:

- Endpoint-family-specific censored-loss weights.
- Interval/Tobit-style likelihood for censored observations.
- Separate diagnostics for `>`, `>=`, `<`, and `<=` records.

This can improve both performance and the defensibility of using ECOTOX
records with inequality qualifiers.

### Priority 5: use ensemble uncertainty, then consider distillation

The 5-seed ensemble is currently the most robust predictor. Next steps:

- Calibrate ensemble prediction intervals.
- Flag high-uncertainty predictions near toxicity thresholds.
- If deployment needs a single model, distill the ensemble into one student
  model only after ensemble behavior is fully characterized.

### Lower Priority: broad new domain-alignment mechanisms

DANN, MMD, CORAL, and larger proxy grids should not be the immediate next step.
Earlier evidence did not justify opening that search space before risk-aware
evaluation, species AD handling, and locked validation are in place.
