# v1.2.43 G 系列预注册协议

## 目标与固定边界

G 系列只比较第三阶段土壤 `neg_log10_mol_kg` 的训练策略；第一、二阶段、数据源、主干、特征、优化器与外层 8:2 测试边界保持不变。数据源固定为 `aggregated_task_records_ptox_soil_mass_molar_qc`，父划分固定为 `M_v1_2_40_ptox_to_soil_molkg_B_random_8_2`，介质适配器关闭，第三阶段固定 `heads_only`、无 soil-pTox replay。

## 新验证边界

旧 v1.2.40 的第三阶段内部验证身份不再用于候选选择。构建前先要求旧 baseline 有效预测人口是父划分第三阶段的严格子集，并在 `aggregate_id`、可确定性重建的 `record_id` 和完整科学身份（`result_ids`、任务头、介质、目标名/家族及原始目标值）三层上双向核验。父划分中仅允许存在“整条任务路由未进入 baseline 且原始支持数低于锁定的 `task_filter.min_total=200`”的原始行；这些行延续 v1.2.40 的既有过滤结果，不进入候选有效人口，并将 ID、哈希、任务及理由完整写入审计。baseline 多出记录、有效路由内缺失记录或达到支持阈值仍缺失均直接失败。有效人口内每条 `result_ids` 必须是可解析的非空序列。新验证集使用种子 17073，从旧第三阶段训练池中按“任务头 × 目标值分位”分层抽取与旧验证集等量的样本；旧验证样本返回训练池。抽样前按共享 `result_ids` 建立 aggregate-result 连通组件，只允许单记录组件进入新验证集，同源 sibling 全部留在训练侧。新训练与新验证、新旧验证都必须同时满足 `aggregate_id` 和 `result_ids` 零重叠，并保持各任务的有效训练/验证支持数不变。

筛选划分 `M_v1_2_43_g_screen` 不含外层测试记录，构建时也不查询父划分的测试身份或计数。只有 fresh validation 原始预测行、指标行、候选汇总和 selection 的完整 canonical SHA-256，以及 screen split summary、每个 manifest/predictions 运行产物的路径与文件/canonical 哈希一并写入不可变 `winner_lock.json` 后，才允许创建含原外层测试集的 `M_v1_2_43_g_final`。已有 lock 必须与当次重新计算的全部内容和证据链逐项一致，任何内容、split summary 或运行产物变化都拒绝复用旧 JSON/CSV。候选筛选阶段既不读取外层测试 assignment，也不计算或汇总外层测试指标。

## 候选定义

| 候选 | 第三阶段改动 |
|---|---|
| G0 | 真正的 `heads_only` 对照；标准 Huber；普通随机采样 |
| G1 | G0 + 任务内等宽目标区间逆频率采样 |
| G2 | G1 + `0.85 × Huber + 0.15 × MSE` |
| G3 | G0 + 共享土壤头、任务家族残差和精确任务残差；不叠加目标区间采样或 MSE |

G1/G2 的采样权重只用第三阶段训练行的原始目标拟合：每个任务的目标范围分为 10 个等宽区间，再按区间频数的倒数采样。权重限制在 `[0.5, 2.0]`，并保持各任务的期望采样总权重不变。这避免了经验分位箱天然等频而使采样器退化为近似普通随机采样。G3 的 family/task residual contribution scale 使用 `alpha=n/(n+tau)`，`tau` 分别为 128/64；它是有限训练下的有效正则化与梯度缩放，不是参数无法补偿的硬约束。family/exact-task 残差分支在第三阶段开始前严格零初始化。

## 缓存与可比性

每个 phase/seed 先运行 G0，并导出第二阶段最优状态；同 phase/seed 的 G1-G3 从该状态开始第三阶段。缓存合同覆盖 seed、DB/source/split 身份、完整预处理映射与特征顺序、基础架构、阶段 1/2 优化协议、权重/辅助目标以及训练样本科学身份和实际编码输入哈希。保存和加载都重新计算 canonical SHA-256，而不直接信任文件自报的哈希。复用时跳过第一、二阶段；筛选与最终阶段使用不同缓存契约。跳过已有运行前还必须核对 manifest seed/split/source/phase、预测边界、当前 DB split 哈希、cache 路径及合同。

## 选择与最终报告

筛选种子固定为 42、3407。候选只有同时满足以下条件才合格：

- 两个种子各自都相对 G0 同时提高原生 `R2` 并降低原生 `MAE`；
- 两种子平均 `delta R2 >= 0.005`；
- 两种子平均 `delta MAE <= -0.005`。

若多个候选合格，先按验证集平均 MAE 升序，再按平均 R2 降序锁定。选择后立即固化 selection JSON/CSV 哈希和 `winner_lock.json`；如已有 lock 与本次内容不同则失败。最终汇总只消费并校验 lock，不重算候选排名，不覆写 selection 文件。锁定后补跑 2042、8417，与 42、3407 共同形成四种子结果。最终仅报告 G0 与 winner 的四种子单模型均值/标准差，以及逐样本预测集成在原生 `mol/kg` 与统一反算 `mg/kg` 尺度上的 R2、RMSE 和 MAE。
