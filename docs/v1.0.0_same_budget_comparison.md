## 结论

1. 在同训练预算下，水相任务不再是负优化。新版全 test R2 从旧版 0.6219 提升到 0.7371，同时 test 样本从 1,799 扩大到 30,473，任务数从 4 扩大到 54。
2. 水相旧共同任务子集也提升，R2 从 0.6219 到 0.6898，说明提升不是只来自新增任务或样本范围改变。
3. 土壤小样本迁移同样改善。旧版全 test R2 为 0.0213，新版全 test R2 为 0.1917；旧共同任务子集达到 0.2671，并且 test 样本从 286 扩大到 963。
4. 新版迁移主任务 R2 为 0.1742，低于水相任务是合理的：土壤 pTox 是跨介质、小样本、任务更复杂的目标，不能按水相随机划分标准要求。
5. 本次结果支持当前科研主线：ECOTOX 大样本水相知识对土壤小样本有可迁移增益，重点应放在 AD 内预测、任务分层指标和土壤小样本迁移改善，而不是把 scaffold 外推作为唯一主线。

## 下一步建议

1. 增加同一 `M_qc_aquatic_to_soil_ptox_adapt_C_f20` 测试集上的 soil-only f20 基线，直接证明水相预训练相对纯土壤小样本训练的增益。
2. 对新版同预算输出合并 AD 标记，报告 AD 内/AD 外 test R2、RMSE、MAE。
3. 按 EC/LC、NOEC、LOEC 三类主任务分别做表，避免辅助任务稀释主线结论。
4. 对土壤迁移结果优先做 ECx/NOEC/LOEC 的 SHAP 与误差分布解释，再决定是否引入 BAF/BCF 的单独辅助目标。
